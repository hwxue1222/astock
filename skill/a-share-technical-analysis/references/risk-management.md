## Protection Lines

### Stop-Loss Protection Line
- Fixed initially; after rise generates floating profit, protection line moves as trailing stop.
- Set at recent support position; effective break = stop-loss sell.
- Support reference: chip peak valley (筹码峰峰谷).

### If Entering Mid-Pull-Up
Stop-loss line set at:
1. Recent rising阳线 lowest point.
2. Recent chip peak valley.
If both layers break, must stop-loss promptly.

### Take-Profit Protection Line
- Set at recent rising阳线 or chip peak valley; use higher as first reference.
- Observe main force capital distribution situation; when main force completes distribution, break rising protection line higher = take-profit sell to protect gains.

### Special Case: Star Line / Divergence Line
If rising阳线 is short-body star line or divergence line, use previous starting阳线 low as protection line.

### High Institution Participation Stocks
Use chip peak valley as take-profit protection; can capture entire trend.

## Main Force Cost Line

### Five Forms of Main Force Cost Line
1. **Opening price** as基准线.
2. **Big阳线二分之一** as基准线.
3. **Two adjacent big阳线**, use first根 opening price as基准线.
4. **Gap up**, use previous根 closing price as基准线.
5. **Long lower shadow big阳线** — special consideration for cost line.

### Functions of Main Force Cost Line
1. Did main force come? (Strength of force)
2. How much main force? (Quantity)
3. Is main force leaving? (Exiting or adding)
4. Is main force strong? Same-attribute comparison (force, quantity, adding)
5. **Main force cost line not broken, any decline can be viewed as washout**.
6. Main force cost line = stop-loss line.

### Application
- Main force cost line not broken + upper accumulation = big阳线 or limit-up board (formula application).
- In trend varieties: observe规律.

### Key Principle
A single stock rising well is not good; multiple stocks in same sector rising well is truly good (板块行为的重要性).

## Stop Loss and Take Profit

### General Rules
- Use main force cost line as dynamic stop-loss.
- Use protection lines based on chip peaks for trend stocks.
- For short-term plays: use big阳线 closing price or opening price as stop.
- For pattern-based entries: use pattern invalidation level as stop.

### Specific Examples
- **左长黑右长红**: Stop-loss = big阳线 closing price (not opening price).
- **进击线**: Stop-loss = day's lowest point.
- **新屠龙刀**: Failure stop-loss = break support (3-5 points).
- **注册制低吸**: Defense = closing price break support = unconditional exit.

## Chip Peak Application

### For Support/Pressure
- Chip peak valley = support reference for stop-loss protection line.
- Chip peak valley = take-profit protection for high-institution stocks to capture full trend.

### For Main Force Behavior
- If拉升中途介入: use recent chip peak valley + recent rising阳线 low as dual protection.
- Both break = prompt stop-loss.
